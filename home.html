🎓 વાર્ષિક

📖 માહિતી
બંને સત્રના ગુણ મળીને
વાર્ષિક પરિણામ બને છે

📖 સોફ્ટવેર ઉપયોગ માર્ગદર્શિકા

1🏫 પ્રથમ સેટઅપ — શાળાકીય માહિતી

  1. ડેશબોર્ડ પર "🏫 શાળાકીય માહિતી" બટન દબાવો
  2. શાળાનું નામ, ગામ, તાલુકો, જિલ્લો, ડાયસ કોડ ભરો
  3. વર્ગ શિક્ષક, આચાર્ય, સી.આર.સી., પે. સેન્ટર નામ ભરો
  4. શાળા લોગો, આચાર્યની સહી, શિક્ષકની સહી — એક વખત upload કરો
  5. પરીક્ષા પ્રકાર પસંદ કરો — પ્રથમ સત્ર / વાર્ષિક
  6. પરિણામ તારીખ, શાળા ઉઘડવાની તારીખ, કુલ કાર્ય દિવસો ભરો
  7. 💾 માહિતી સેવ કરો દબાવો
💡 શાળાની માહિતી એક જ વખત ભરવાની છે — તે બધા પત્રકોમાં automatic આવશે.

2👦 વિદ્યાર્થી માહિતી + ગુણ એન્ટ્રી

  1. ડેશબોર્ડ પર "👨‍🎓 વિદ્યાર્થી માહિતી અને ગુણ એન્ટ્રી" બટન દબાવો
  2. "+ નવો વિદ્યાર્થી" — દરેક વિદ્યાર્થી માટે નવી row
  3. નામ, GR No., જન્મ તારીખ (dd-mm-yyyy), સરનામું, ફોટો, જાતિ, M/F ભરો
  4. દરેક વિષયના 6 columns:
    • પ્રથમ સત્ર: ત્રિમાસિક (40) + સત્રાંત (80) + સ્વ અધ્યયન (20) = 140
    • દ્વિતીય સત્ર: ત્રિમાસિક (40) + સત્રાંત (80) + સ્વ અધ્યયન (20) = 140
  5. Patrak-B column: Std 3-5 → 200, Std 6-8 → 400
  6. 💾 Auto-save 2 સેકન્ડ પછી — ઉપર "💾 ઓટો-સેવ" બતાવે
  7. 📥 Excel Import — પહેલાથી Excel હોય તો
  8. 📥 CTS ડેટા — Government CTS ફાઈલ import + auto-translate
  9. 🖼️ બધા ફોટા એકસાથે — Folder select કરો, Roll No. થી auto-assign થશે (1.jpg, 2.jpg...)
⚠️ નામ, GR, DOB સચોટ ભરો — Marksheet / Patrak-F માં automatic આવશે.

3🎯 પત્રક-B : વ્યક્તિત્વ વિકાસ

  1. ડેશબોર્ડ પર "🎯 પત્રક-B" બટન દબાવો
  2. Structure: 8 ક્ષેત્ર × 5 વિધાન = 40 categories
  3. દરેક category: Max 5 (Std 3-5) કે Max 10 (Std 6-8)
  4. પ્રથમ સત્ર / દ્વિતીય સત્ર tabs — બંને અલગ
  5. "🎲 આ સત્ર Distribute" — Auto random distribution
  6. Manual entry પણ કરી શકાય — દરેક cell માં number type
  7. 💾 Auto-save 2 sec
  8. "🖨 પ્રિન્ટ (20/પેજ)" — A4 Landscape, 20 વિદ્યાર્થી/પેજ
💡 પહેલા ગુણ એન્ટ્રીમાં Patrak-B total ભરો → પછી અહીં Distribute થી categories auto-ભરાશે.

4📋 પત્રક-C Front Page (SCE Cover)

  1. ડેશબોર્ડ પર "📋 પત્રક-C front" બટન દબાવો
  2. A4 Portrait — Frame border + 2 Saraswati images
  3. SCE Title + Patrak-C Badge automatic
  4. Statistics Table: જાતિ × ગ્રેડ (A/B/C/D/E) × કુમાર/કન્યા
  5. શાળાની માહિતી automatic આવે
  6. "🖨 પ્રિન્ટ / PDF" બટન દબાવો

5📋 પ્રગતિ પત્રક (Patrak-F)

  1. ડેશબોર્ડ પર "📋 પ્રગતિ પત્રક (પત્રક F)" બટન દબાવો
  2. A4 Landscape — 2 વિદ્યાર્થી/પેજ
  3. આગળ (Front): વિષય ગુણ, ગ્રેડ, રેન્ક, હાજરી + વાલી/શિક્ષક/આચાર્ય સહી
  4. પાછળ (Back): પ્રગતિ પત્રક — નામ, ગામ, જન્મ તારીખ, ફોટો, સરનામું
  5. કેન્દ્રમાં ✂ કટ લાઈન — બે ભાગમાં કાપવા
  6. "📄 Bulk PDF" — બધા વિદ્યાર્થી એક PDF
  7. "🖨 Bulk Prints" — બધા પેજ પ્રિન્ટ
  8. "💬 WhatsApp" — Current / Bulk
💡 પ્રિન્ટ પ્રિવ્યુમાં Layout → Landscape, Margins → None, Headers/Footers → બંધ.

6🖨 પ્રિન્ટ / PDF સૂચનાઓ

  • Browser: Google Chrome અથવા Microsoft Edge
  • Print Color: Exact / Background Graphics ON
  • Page Size: A4
  • Orientation: Portrait (Marksheet, Patrak-C) | Landscape (Patrak-F, Patrak-B)
  • Margins: None અથવા Minimum
  • Headers / Footers: બંધ કરો
  • PDF માટે: Print → Destination → "Save as PDF"
⚠️ પ્રિન્ટ પ્રિવ્યુમાં કોઈ column કપાય તો Margin ઓછું કરો અથવા Scale ને 90-95% કરો.

7🎓 આગલા વર્ષે પ્રમોટ (Std 3-8)

  1. ડેશબોર્ડ પર "🎓 આગલા વર્ષે પ્રમોટ" બટન દબાવો
  2. Chain: 3 → 4 → 5 → 6 → 7 → 8 → પાસ આઉટ
  3. દરેક વિદ્યાર્થીના માર્ક્સ શૂન્ય થશે, નામ/GR/ફોટો રહેશે
  4. જૂનો ડેટા History માં automatic સેવ થશે
⚠️ પ્રમોટ કરતાં પહેલાં Excel Export થી Backup લેવો ફરજિયાત!

8💬 WhatsApp દ્વારા મોકલો

  • Send WhatsApp (Current) — હાલનો વિદ્યાર્થી
  • Send WhatsApp (Bulk) — બધા વિદ્યાર્થી (2 sec gap)
  • WhatsApp SMS Edit — મેસેજ customize કરો
  • Image Share — Marksheet ની image copy + manually send
💡 વિદ્યાર્થીના Contact Number માં 10 digit હોવો જોઈએ — automatic +91 ઉમેરાશે.

9⚙️ સામાન્ય સમસ્યાઓ

  • તારીખ ખોટી દેખાય: DD-MM-YYYY format વાપરો
  • Data ગુમ: Browser closed કરો તો IndexedDB માં સેવ રહે — ફરી ખોલો
  • Fonts દેખાય નહીં: Internet connection check કરો
  • WhatsApp ના ખૂલે: Browser popup allow કરો
  • Excel Import fail: Column headers standard રાખો
  • Backup: દર રોજ Excel Export કરો
