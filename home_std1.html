1🏫 પ્રથમ સેટઅપ — શાળાકીય માહિતી

  1. ડેશબોર્ડ પર "🏫 શાળાકીય માહિતી" બટન દબાવો
  2. શાળાનું નામ, ગામ, તાલુકો, જિલ્લો, ડાયસ કોડ ભરો
  3. વર્ગ શિક્ષક, આચાર્ય, સી.આર.સી., પે. સેન્ટર નામ ભરો
  4. શાળા લોગો, આચાર્યની સહી, શિક્ષકની સહી — એક વખત upload કરો
  5. 💾 માહિતી સેવ કરો દબાવો

2👦 વિદ્યાર્થી માહિતી + ગુણ એન્ટ્રી

  1. ડેશબોર્ડ પર "👦 વિદ્યાર્થી માહિતી + એન્ટ્રી" બટન દબાવો
  2. નામ, GR No., જન્મ તારીખ, સરનામું, ફોટો, જાતિ ભરો
  3. દરેક વિષયના ગુણ ભરો (પ્રથમ સત્ર + દ્વિતીય સત્ર)
  4. 💾 Auto-save 2 sec પછી automatic
  5. Excel Import/Export + CTS Import ઉપલબ્ધ

3📊 પરિણામ / માર્કશીટ

  1. ડેશબોર્ડ પર "📊 પરિણામ" બટન દબાવો
  2. પ્રથમ સત્ર / વાર્ષિક પરિણામ જુઓ
  3. "📜 માર્કશીટ" — વિદ્યાર્થીવાર marksheet
  4. "🖨 પ્રિન્ટ / PDF" — A4 Portrait

4🎯 પત્રક-B : વ્યક્તિત્વ વિકાસ

  1. "🎯 પત્રક-B" બટન દબાવો
  2. પ્રથમ સત્ર / દ્વિતીય સત્ર tabs
  3. "🎲 Distribute" — Auto random distribution
  4. Manual entry પણ શક્ય
  5. "🖨 પ્રિન્ટ" — A4 Landscape, 20 વિદ્યાર્થી/પેજ

5📋 પ્રગતિ પત્રક (Patrak-F)

  1. "📋 પ્રગતિ પત્રક (પત્રક F)" બટન દબાવો
  2. A4 Landscape — 2 વિદ્યાર્થી/પેજ
  3. આગળ: ગુણ, ગ્રેડ, રેન્ક | પાછળ: પ્રગતિ પત્રક
  4. "📄 Bulk PDF" કે "🖨 Bulk Prints"

6📘 HPC (Holistic Progress Card)

  1. ડેશબોર્ડ પર HPC section માં વિદ્યાર્થી પસંદ કરો dropdown
  2. "📘 પ્રથમ સત્ર HPC કાર્ડ" કે "દ્વિતીય સત્ર HPC કાર્ડ" બટન દબાવો
  3. 12-પેજ HPC કાર્ડ ખૂલશે
  4. Competency ratings, વાલી પ્રતિભાવ, પોર્ટફોલિયો ભરો
  5. "🖨 Print" / "PDF" — A4 Portrait
  6. Sidebar માંથી કોઈપણ પેજ પર jump કરો
💡 HPC ડેટા LocalStorage માં student-wise સેવ થાય છે.
