શિક્ષકો

Backup અને જૂનો ડેટા Import

જૂનો browser ડેટા આપમેળે કોઈ શાળા સાથે જોડાતો નથી. ફક્ત આ શાળાનો જ ડેટા import કરો. Import માત્ર ખાલી recordsમાં થશે; હાલનો server ડેટા overwrite નહીં થાય.

Browser import માત્ર એ જ browser અને origin (જેમ કે localhost:3001)ના જૂના ડેટાને વાંચી શકે છે. બીજા domain પર લઈ જવા પહેલાં અહીં import કરીને JSON backup download કરો.
