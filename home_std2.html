1🏫 પ્રથમ સેટઅપ — શાળાકીય માહિતી

  1. ડેશબોર્ડ પર "🏫 શાળાકીય માહિતી" બટન દબાવો
  2. શાળાનું નામ, ગામ, તાલુકો, જિલ્લો, ડાયસ કોડ ભરો
  3. વર્ગ શિક્ષક, આચાર્ય, સી.આર.સી., પે. સેન્ટર ભરો
  4. શાળા લોગો, આચાર્યની સહી, શિક્ષકની સહી upload કરો
  5. 💾 માહિતી સેવ કરો દબાવો
💡 Std 2 નો ડેટા Std 3-8 થી સંપૂર્ણ અલગ (અલગ Database) રહે છે.

2👦 વિદ્યાર્થી માહિતી + D2 પત્રક એન્ટ્રી

  1. ડેશબોર્ડ પર "👦 વિદ્યાર્થી માહિતી + એન્ટ્રી" બટન દબાવો
  2. વિદ્યાર્થી માહિતી ભરો: નામ, GR, જન્મ તારીખ, સરનામું, ફોટો, જાતિ, M/F
  3. D2 પત્રક — 3 tabs:
    • 📗 ભાષા પર્યાવરણ — 20 items
    • 📘 ગણિત — 20 items
    • 📙 વ્યક્તિત્વ વિકાસ — 11 items
  4. દરેક item સામે dropdown: A / B / C
    • A = 3 points (હરિયાળો)
    • B = 2 points (પીળો)
    • C = 1 point (લાલ)
  5. Auto-calculate: A count, B count, C count, Total, %, Grade
  6. પ્રથમ સત્ર / દ્વિતીય સત્ર tabs — બંને અલગ entry
  7. 💾 Auto-save automatic
  8. 📥 Excel Import / 📤 Excel Export
💡 Excel Export → Excel માં ફેરફાર → Excel Import → બધા students auto update.

3🖨️ D2 પત્રક પ્રિન્ટ

  1. ડેશબોર્ડ પર D2 પત્રક buttons માંથી પસંદ કરો:
    • "🖨️ ભાષા પર્યાવરણ પત્રક"
    • "🖨️ ગણિત પત્રક"
    • "🖨️ વ્યક્તિત્વ વિકાસ પત્રક"
    • "🖨️ ત્રણેય D2 પત્રક પ્રિન્ટ" — બધા એકસાથે
  2. સત્ર પસંદ કરો: પ્રથમ / દ્વિતીય
  3. A4 Landscape — Table view + A/B/C count + % + Grade
  4. "🖨️ આ પત્રક પ્રિન્ટ" — એક પત્રક
  5. "🖨️ આ સત્રનાં ત્રણેય પત્રક" — ત્રણેય એક PDF
💡 પ્રિન્ટ પ્રિવ્યુમાં Landscape, Margins → Minimum, Background Graphics ON.

4📋 ગ્રેડિંગ સિસ્ટમ

  • A → 80%+ (ઉત્તમ)
  • B → 65-79% (સારો)
  • C → 50-64% (મધ્યમ)
  • D → 35-49% (સુધારો જરૂરી)
  • E → 35% થી નીચે (નબળો)
💡 Std 2 માં હંમેશા PASS — Std 8 જેવો FAIL logic નથી.

5🖨 પ્રિન્ટ / PDF સૂચનાઓ

  • Browser: Chrome / Edge
  • Print Color: Exact / Background Graphics ON
  • Orientation: Landscape (બધા D2 પત્રક)
  • Margins: Minimum / None
  • Headers/Footers: બંધ
  • PDF: Print → Destination → "Save as PDF"
